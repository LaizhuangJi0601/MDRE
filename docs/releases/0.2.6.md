# MDRE for Windows 0.2.6

Includes all 0.2.6 improvements through **updata2**.

## What's new

- **Word conversion:** import and export `.docx`, including common structures and equations, through an external Pandoc installation.
- **Bilingual workspace:** English and Simplified Chinese menus, messages, settings, and three reorganized, searchable offline guides.
- **Settings and windows:** categorized settings with search, preview, apply/reset controls, and safer draft recovery. Desktop settings, help, and shortcuts use dedicated windows; extension dialogs have consistent window controls.
- **Reading layout:** 60%–100% width outside A4, four text alignments, and image display preferences across A4 and continuous layouts.
- **Editing:** selection-wide paragraph formatting, clearer table menus, and improved composition input handling.
- **File handling:** desktop external-save detection, conflict preservation, reading-position recovery, and activation of existing tabs when reopening a path.
- **Refinements:** configurable fade transitions, fewer duplicate font assets, on-demand resource loading, and document-dependent exports disabled in empty workspaces.

## Installation

Download `mdre.exe` and run it on Windows 10/11 x64 with Microsoft Edge WebView2 Runtime installed. Verify the download with `SHA256SUMS.txt`.

Word conversion requires a separately installed Pandoc; select the full executable path (`pandoc.exe` on Windows). Complex Word formatting may simplify. TeX conversion is not included.
