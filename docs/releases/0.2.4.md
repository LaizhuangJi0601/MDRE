# MDRE 0.2.4

This release improves editing stability, table selection, typography, views, search and export, and fixes HTML/PDF export of local images referenced by absolute paths.

## What's new

- **Editing:** fixed list and task-list backspace and exit behavior, kept extra blank paragraphs inside lists with `<p></p>`, and escaped numeric paragraphs such as `1\.` while `1. text` still parses as an ordered list in source.
- **Block deletion:** horizontal rules, tables and cross-paragraph selections can be selected and deleted with Delete/Backspace and still pass re-parse validation.
- **Typography:** choose px or em font-size units under Appearance & reading (px by default); switching units converts the body size, and the toolbar and context menus show only the selected unit.
- **Context menus:** grouped by text formatting, text color, headings, highlight, font size, insertion, tables and block operations.
- **Table selection:** select a whole table, drag a text selection, Ctrl/Cmd-click multiple cells or Shift-click a rectangular range, then align in one step that undoes in one step.
- **Saving:** fixed the extension's 60-second autosave not starting; saves are confirmed by VS Code's document model, and unsaved, composing, recovering or conflicting documents are never overwritten.
- **Views and status:** default sidebar and toolbar visibility, full editing, focus, immersive focus and A4 view presets with a free mode, F11 focus toggle, and save status, character/word counts, encoding and line/column in the status bar.
- **Search and help:** wider find box with previous match (Shift+Enter), automatic scrolling to matches, and wrapping help tables.
- **Export:** HTML/PDF export now reads and embeds local images referenced by `<file:///...>` URLs; choose paged (A4) or long-page PDF, with a hint to use paged export when the long page exceeds the print engine limit.
- **Branding and refinements:** a transparent MD logo and a dedicated Markdown document icon, view presets with restored combinations, batch table alignment, previous-match search, paged and long-page PDF export, an autosave fix, and list, paragraph and rule fixes.

## Installation

Download `mdre.exe` and run it on Windows 10/11 x64 with the Microsoft Edge WebView2 Runtime installed.

The VS Code extension is distributed separately as `mdre-vscode-0.2.4.vsix`. Verify downloads with `SHA256SUMS.txt`.
