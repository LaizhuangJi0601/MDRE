# MDRE for Windows 0.2.7

Version 0.2.7 keeps the desktop app and the VS Code extension on the same feature set and focuses on reliability and editing comfort. This release was verified with functional tests only; it does not repeat startup, open-time or memory benchmarks.

## What's new

- **Mermaid reliability:** diagram source is normalized into valid SVG before display, so labels that contain `<br/>` line breaks, Chinese text, quotes or parentheses render reliably instead of showing a broken image with the raw source as alternative text. Flowchart, sequence, class, state, Gantt, pie, ER, mindmap, timeline, journey, quadrant, Git graph, XY chart, requirement, Sankey, C4, block and packet diagrams are covered; invalid syntax shows a readable hint such as "Syntax error near line N" and only that diagram is affected.
- **In-place cross-fade transitions:** view, tab, dialog, menu, theme and mode changes now cross-fade in place for about 0.8 seconds — outgoing content fades out where it is and incoming content fades in at its final position, without sliding or fly-in motion. Flickers during some transitions are fixed; composition input stays untouched and the system reduced-motion preference is respected.
- **Settings and windows:** the VS Code extension opens settings as a popup inside the editor instead of a separate editor page. Settings, help and shortcut windows remember their last position and size and stay inside the visible screen. Body and monospace font choices list fonts installed on the system.
- **Word export:** exported `.docx` files follow the Markdown content and no longer prepend a generated title such as "MDRE document snapshot".
- **Reading layout:** the A4 zoom level (25%–250%) is remembered globally and reused for every newly opened document.
- **Large documents:** parsing is about 40–45% faster and per-keystroke main-thread work drops by about 64% for 130 KB-scale documents.
- **Help and links:** the offline-help footer is removed so the content area gets more room. In-page anchors accept `#heading-text`, `#sec-…`, URL-encoded and case-insensitive forms and explicit `{#id}`; relative `.md` links open in a new tab, with a clear hint for unsaved documents.

## Installation

Download `mdre.exe` and run it on Windows 10/11 x64 with the Microsoft Edge WebView2 Runtime installed. Verify the download with `SHA256SUMS.txt`.

Word conversion requires [Pandoc](https://pandoc.org/installing.html).
