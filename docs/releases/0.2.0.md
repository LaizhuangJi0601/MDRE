# MDRE 0.2.0

This release adds A4 reading and editing layouts, integrates the sidebar, and restores the previous session at startup.

## What's new

- **A4 layout:** continuous and paged A4 views with 25%–250% zoom, up to three pages per row, page numbers and body alignment; paging offsets at non-100% zoom are fixed.
- **Sidebar:** the file list and outline share one sidebar with a resizable width, a collapsible outline and scrolling for long outlines.
- **Session restore:** the last folder and unclosed documents are restored on startup; recent files and folders keep up to five entries each.
- **Interface:** refined toolbar, underline, image display, code-block themes, settings dialog and welcome page.
- **Documentation:** the user guide, syntax reference and third-party notices are updated and stay in sync with the in-app help.

## Installation

Download `MDRE-0.2.0-windows-x64.zip`, extract it and run `mdre.exe`; a standalone `mdre.exe` is also available.

Windows 10/11 x64 and the Microsoft Edge WebView2 Runtime are required.
