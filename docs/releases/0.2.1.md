# MDRE 0.2.1

## What's new

- **Tables:** align cell content left, center or right from the table context menu, with the current alignment indicated.
- **Context menus:** actions are grouped by text formatting, tables and block operations for a simpler editing surface.
- **Settings and theme:** improved settings layout and fixed the saved theme not being applied at startup.
- **Navigation:** in-page links and heading anchors work again; the outline highlights with the document and follows continuous, paged and zoomed A4 views.
- **Parsing fixes:** documents containing superscripts, subscripts, links or images no longer fail to open; horizontal rules and HTML source editing are improved.
- **Documentation:** the 0.2.1 help is reorganized by Markdown and HTML syntax, with notes on standard, common and MDRE-specific features.

## Installation

Download `mdre.exe` and run it on Windows 10/11 x64 with the Microsoft Edge WebView2 Runtime installed.

The app supports synchronized Markdown and rich-text editing, visual equation editing, Mermaid diagrams, and HTML/PDF export.
