# MDRE 0.1.0

The first public release: an offline Markdown editor that keeps Markdown source and rich text in sync on Windows.

## What's new

- **Synchronized editing:** edit rich text directly while the Markdown source stays in sync, with one shared undo history.
- **Equations and diagrams:** visual equation editing, Mermaid diagrams, and syntax-highlighted code blocks.
- **Export:** export the current document to HTML or PDF.
- **Offline by design:** editor resources are bundled and no network connection is required.

## Installation

Download `MDRE_v0.1-windows-x64.zip`, extract it and run `mdre.exe`; a standalone `mdre.exe` is also provided. The ZIP includes the user guide, the MIT license and third-party notices.

Windows 10/11 x64 and the Microsoft Edge WebView2 Runtime are required. MDRE is released under the MIT license; third-party components keep their own licenses.
