# 使用指南

MDRE 将 Markdown 源码编辑、富文本排版与阅读整合在同一工作区。本页汇总当前版本的操作方法；标记与兼容范围见[语法参考](MDRE语法.md)，开源授权见[声明与许可](MDRE声明.md)。

## 开始使用

| 操作 | 入口 |
| --- | --- |
| 新建／打开 | 欢迎页或“文件”菜单；Ctrl+N 新建，Ctrl+O 打开。 |
| 保存／另存为 | “文件”菜单；Ctrl+S 保存，Ctrl+Shift+S 另存为。 |
| 文件标签 | Ctrl+Tab 切换，Ctrl+W 关闭，拖动可排序；加号打开欢迎页，关闭最后一个文件后回到欢迎页。 |
| 最近打开 | “文件”菜单分别保留最近 5 个文件和文件夹；同一路径复用已有标签，不同目录同名文件可分别打开。 |
| 文件关联 | 在设置中注册 `.md` 文件关联后，可双击 Markdown 文件启动 MDRE。 |

侧栏在文件列表、图片管理和大纲导航间切换。文件夹支持展开与刷新；已打开目录时，侧栏新建按钮会在该目录创建文件并避开重名。侧栏边缘调整宽度，文件列表与已打开文档间的分隔线调整区域高度。大纲可折叠，重新展开侧栏会保留上次分类。

启动时恢复上次工作区、未关闭文件、当前标签和侧栏状态；正式文件读取磁盘最新内容，未保存内容通过恢复快照处理。不可用路径会提示并跳过。

## 编辑与格式

源码与富文本双向同步，共用撤销历史。工具栏按历史、字体、色彩、段落、插入和结构分组；窗口较窄时，可用滚轮横向浏览。阅读模式保留选择、复制、查找和导出，修改命令置灰。

| 内容 | 操作 |
| --- | --- |
| 文字与段落 | 选中文字设置粗体、斜体、下划线、删除线、字号、上下标或颜色；标题、段落等命令可批量应用于所选多行、多段。 |
| 颜色与高亮 | 点击预选色块应用，打开色板换色；右键菜单可恢复文字颜色或清除高亮。 |
| 列表与结构 | 使用工具栏或右键菜单插入列表、引用、链接和分隔线；“块操作”提供上移、下移、删除、转换与源码片段编辑。空列表项按 Enter 或 Backspace 可退出列表。 |
| 数学公式 | 双击公式进入可视化编辑，支持虚拟键盘和块级公式编号；确认后写回源码，取消或 Esc 放弃修改。 |
| Mermaid 图表 | 从插入菜单创建，双击图表或选择“编辑图表”修改源码；可用删除按钮或 Delete／Backspace 移除。 |
| 代码块 | 直接编辑代码、切换语言或折叠内容；固定行号，可视区域约 20 行，超出部分在块内滚动。支持浅色、深色代码主题。 |
| HTML 与元数据 | 保留原始标签和属性；简单行内文字可直接编辑，复杂组件通过源码栏或“块操作 → 编辑源码片段”修改。 |

下划线保存为 `<u>内容</u>`。字号支持 px 与 em，切换单位按 16px = 1em 换算；px 预设为 8–24px，间隔 2px。具体标记、公式和 HTML 支持范围见[语法参考](MDRE语法.md)。

## 表格与单元格

在富文本中直接编辑表格，Enter 在单元格内换行。右键“表格”菜单按结构、对齐和列宽分组；每次操作均可一步撤销。

| 操作 | 方法 |
| --- | --- |
| 选择 | 拖选跨单元格文字；Ctrl／Cmd+单击切换多选，Shift+单击选择矩形区域；“全选表格”选择整表。 |
| 插入与删除 | 在右键菜单中插删行列；列宽与合并跨度同步调整，无法安全处理的操作会提示并保持原文。 |
| 调整列宽 | 拖动列边框预览，松开提交；双击按内容适应。菜单提供均分各列、适应内容和恢复自动列宽。单列最小 4%，总宽不超过 100%。 |
| 水平对齐 | 左对齐、左右居中、右对齐互斥。Markdown 表格按选中单元格所在列设置，HTML 表格按单元格设置；未选区域保留原对齐。 |
| 上下居中 | 独立开关，可与任一水平对齐组合；首次启用时转为 HTML 表格。 |
| 合并与拆分 | 仅合并矩形区域，内容按阅读顺序以换行连接；拆分后内容留在左上单元格。 |
| 转为 Markdown 表格 | 无合并、无上下居中的 HTML 表格可转换；执行前提示格式损失。列宽保留，水平对齐取每列首行，列内混合对齐按左对齐处理。 |

手动列宽保存为表格后的 HTML 注释。首次合并或启用上下居中时，整表转为 HTML；其他阅读器可能显示源码或忽略样式。HTML／PDF 导出保留列宽、合并与对齐，合并单元格不跨页拆分。

## 图片与资源

插入按钮、拖入原文件或粘贴文件时，优先引用原文件绝对路径；截图等无原文件的图片写入持久图片库，失败时尝试 `assets`。相对路径按 Markdown 所在目录解析，未保存文档也可插图。

默认图片显示同时适用于 A4 与非 A4 视图。“适应正文宽度”按比例填满正文容器；“原始尺寸”采用源码指定宽度，超宽时缩小。悬停可预览，打开大图后可旋转；调整图片宽度会写回源码。

“图片管理”按文档引用顺序列出名称与路径：单击定位引用，双击名称打开本地目录。网络图片显示地址，内嵌图片标记为 data URI；两者没有本地目录可打开。

移动原图会影响绝对路径引用。需要迁移或分享文档时，使用“可分享副本”收集本地图片。

## 视图与阅读

底部视图菜单提供四种预设；手动调整后显示“自由模式”。重新打开时恢复最后的视图组合。

| 视图 | A4 | 源码栏 | 侧栏 | 编辑功能区 |
| --- | --- | --- | --- | --- |
| 全量编辑 | 关闭 | 显示 | 显示 | 显示 |
| 专注模式 | 开启 | 隐藏 | 显示 | 隐藏 |
| 沉浸专注 | 开启 | 隐藏 | 隐藏 | 隐藏 |
| A4视图 | 开启 | 隐藏 | 显示 | 显示 |

F11 在专注模式与全量编辑间切换，侧栏与工具栏可独立显隐。阅读模式暂时隐藏源码并禁用编辑；返回编辑模式后，恢复原来的源码显示选择。

- **非 A4 页宽：**底部滑条范围 60%–100%，无历史设置时默认 80%，调整后自动记忆；仅影响屏幕阅读，不改变导出。正文默认两端对齐，可在“纸张与图片”选择两端、左、居中或右对齐。
- **A4 排版：**纸张为 210 × 297mm，可选连续或分页排版；正文支持左对齐、居中、右对齐和两端对齐，默认两端对齐。
- **缩放与分页：**在渲染区按住 Ctrl 滚轮，范围 25%–250%。分页先按固定纸张排版再缩放，每行依可用宽度排列 1–3 页，页码从左到右、从上到下递增。
- **阅读位置：**重新打开文件恢复阅读锚点与源码滚动位置；双栏滚动按可见文字联动，兼容连续、分页与缩放。

页码、页间空白和分页装饰不写入 Markdown，也不产生撤销步骤。过高的不可分块或单元格在块内滚动，以保留完整内容。

## 保存与恢复

- **自动保存：**有正式路径且已修改的文档每 60 秒保存；组合输入、恢复副本、冲突和文件操作期间暂缓。无路径文档需先手动保存。
- **恢复快照：**独立记录编辑内容，供意外退出后恢复；快照不代替正式保存。保存前备份可在设置中调整份数，0 为关闭。
- **外部修改：**无本地修改时自动载入；存在未保存内容时保留双方版本，可比较、另存本地副本或载入外部版本。文件列表同步刷新并保留展开状态。
- **编码与换行：**支持 UTF-8、UTF-16LE／BE 和 GBK，保留原编码、BOM 与换行。无法用原编码保存时，可转为 UTF-8。
- **关闭文档：**未保存内容会询问保存、放弃或取消；取消后继续保留当前工作区。

源码的 UTF-8 大小达到 1MiB 时，预览改为手动刷新，以保持输入响应。点击刷新或按 Ctrl+Shift+R 更新渲染。

## 查找与导航

Ctrl+F 打开查找，Ctrl+H 打开替换；支持区分大小写、全字匹配与正则表达式。Enter 定位下一个结果，Shift+Enter 定位上一个，替换可撤销。

大纲按标题层级导航，选中项随阅读位置更新；点击标题将其定位到页面上方。文档目录与页内链接使用标题锚点；需要固定地址时，为标题指定显式 ID。跳转到行可从菜单或快捷键进入。

## 复制与粘贴

渲染栏右键选择“复制为富文本”（Ctrl+Shift+C）：有选区时复制选区，无选区时复制全文，同时写入富文本与纯文本。保留常用文字格式、列表、表格、链接和图片，不带页码、行号等界面装饰。源码栏复制始终输出 Markdown。

MDRE 颜色样式按下划线降级，高亮和字号按加粗降级；无法映射的内容会提示。Ctrl+V 优先将剪贴板 HTML 转为 Markdown，转换失败时粘贴纯文本。

| 剪贴板内容 | 处理方式 |
| --- | --- |
| 标题、段落、列表、引用、代码、链接、普通表格 | 转为对应 Markdown，识别常见 Word 标题、列表及 Excel／网页表格。 |
| 颜色、字体、字号、行距、对齐 | 忽略 Markdown 无法表达的格式，并报告数量。 |
| 合并表格、单元格内复杂内容 | 降级为段落或文本并提示。 |
| 内嵌 data URI 图片 | 写入持久图片库，按内容去重。 |
| HTTPS 图片 | 保留网络地址；离线可用性取决于图片来源。 |
| 无法读取的临时图片 | 跳过并提示数量。 |

脚本、iframe 和事件属性会被清除。HTML 超过 5MB 或图片超过 20 张时回退纯文本；代码块和行内代码始终按纯文本处理。输入法组合输入需先完成提交，一次粘贴仅产生一步撤销。

## 导出与分享

未打开文档时，Word 与可分享副本导出入口禁用。导出使用当前文档的内容快照，原 Markdown 与源图片保持不变。未保存修改不会因导出而被标记为已保存。

| 格式 | 用途与范围 |
| --- | --- |
| HTML | 嵌入本地图片，保留公式、图表及常用排版，适合离线浏览。 |
| PDF | 可选 A4 分页或纵向长页。长页超出打印引擎上限时，改用分页导出。桌面使用系统 WebView2 打印。 |
| 可分享副本 | 将 Markdown 与可读取的本地图片打包为 ZIP，图片改为包内相对路径；网络图片与 data URI 不写入 ZIP，缺失图片跳过并提示。 |
| Word（.docx） | 通过本机 Pandoc 转换，配置与边界见“Word 转换”。 |

可分享副本保留文档目录内已有相对路径；绝对路径图片按内容哈希收集到 ZIP 的 `images/` 目录。完成后在状态栏查看输出路径、大小与警告。

## Word 转换

支持 `.docx` 与 Markdown 互转，调用本机外部 Pandoc。MDRE 不捆绑、下载或升级 Pandoc；无需安装 Word 或 TeX 环境。旧 `.doc` 与 TeX 互转不在支持范围内。

### 配置 Pandoc

在“设置 → Word 转换”查看当前可执行文件路径。自动检测会检查 PATH 和常见安装目录；显示检测结果不会固定路径。手动填写或选择后使用指定程序，清空可恢复自动检测；未检测到时显示选择提示。

Windows 路径必须具体到 **`pandoc.exe` 文件**，例如 `D:\Tools\Pandoc\pandoc.exe`，不能只填文件夹或附加命令参数。插件在 macOS／Linux 下指定 `pandoc` 可执行文件。可从 [Pandoc 官网](https://pandoc.org/installing.html) 安装，点击“检测 Pandoc”确认路径与版本。

### 导入与导出

| 操作 | 方法 |
| --- | --- |
| 导入 Word | 从“文件 → 导入 Word（.docx）”选择 `.docx`，再指定新的 `.md` 文件。导入拒绝覆盖已有 Markdown，成功后打开新文档，原 Word 保持不变。 |
| 导出 Word | 在“导出 → 导出 Word（.docx）”指定输出位置；“Word 参考样式”可选择完整 `.docx` 文件，留空采用 Pandoc 默认样式。 |
| 图片资源 | 导入的内嵌图片提取到 Markdown 同目录下的 `文件名.assets-唯一编号` 文件夹，并使用相对引用；移动或分享时一并携带。导出时缺失图片会中止转换并报告。 |
| 公式与结构 | 支持常用文字、列表、代码、链接、普通表格和常见公式；公式转换为 Word 原生公式，可再导回 Markdown。 |

复杂页眉页脚、分节、修订、批注、浮动文本框、域及页面布局可能简化；颜色、字号和复杂表格不保证无损往返。请核对重要公式、引用与表格。状态栏提供输出位置及警告；取消、失败或超时均保留原文档。

## 设置与快捷键

通过“设置 → 打开设置页面”进入独立窗口，可跨屏移动并记忆位置。设置按外观与阅读、纸张与图片、侧栏导航、编辑与文件、Word 转换和快捷键分类，可搜索选项；阅读预览仅显示在外观分类。

| 操作 | 作用 |
| --- | --- |
| 应用 | 保存修改，保留设置页。 |
| 确定 | 保存修改并关闭设置页。 |
| 取消／单独关闭设置 | 丢弃尚未应用的修改。 |
| 恢复本页默认 | 仅重置当前分类，应用或确定后保存。 |
| 正常退出应用 | 确认文档处理后，验证并保存设置草稿，再关闭设置窗口；无效设置或写入失败会提示并保留窗口。 |

主题、字体、字号、行距和视图设置沿用已保存配置；默认启动模式在下次启动时应用。界面语言可选简体中文或 English，应用后同步切换菜单、提示、设置与离线帮助；文档内容、文件名和许可原文保留。界面动画可选跟随系统、开启或关闭，默认跟随系统的减少动态效果设置；页面切换使用清晰的淡入淡出，组合输入期间保持输入面稳定。

| 默认快捷键 | 操作 |
| --- | --- |
| Ctrl+S／Ctrl+Shift+S | 保存／另存为 |
| Ctrl+Z／Ctrl+Y 或 Ctrl+Shift+Z | 撤销／重做 |
| Ctrl+F／Ctrl+H | 查找／替换 |
| Ctrl+Shift+V | 编辑／阅读模式 |
| Ctrl+Shift+O | 展开／收起侧栏 |
| Ctrl+G | 跳转到行 |
| Ctrl+Shift+R | 刷新渲染 |
| Ctrl+U／Ctrl+Shift+C | 下划线／复制为富文本 |
| F11 | 专注模式／全量编辑 |

帮助与独立快捷键页使用顶部窗口控件；帮助页不再提供底部关闭按钮。桌面独立窗口使用系统的最小化、最大化、关闭与边缘缩放；插件内窗口支持顶部控件和四边缩放，最小化折叠内容，最大化填满可用视口。快捷键页可录入组合键，Esc 恢复该项默认值。帮助文档与公式资源离线可用；外部链接仅在点击后交给系统浏览器。帮助中的搜索筛选当前文档，左侧目录用于章节定位。
