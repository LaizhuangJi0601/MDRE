# MDRE 使用说明

MDRE **0.2.5** 是本地 Markdown 编辑器，支持源码与富文本双向编辑，并提供阅读模式。本页说明当前版本的功能与操作方法。

## 文件与模式

| 功能 | 使用方法 |
| --- | --- |
| 新建、打开、保存 | 在“文件”菜单操作；默认快捷键为 Ctrl+N、Ctrl+O、Ctrl+S，另存为 Ctrl+Shift+S。 |
| 文件标签 | 同时打开多个文件；拖动标签调整顺序，Ctrl+Tab 切换，Ctrl+W 关闭。标签尾部加号打开新欢迎页，关闭最后一个标签后回到欢迎页。 |
| 最近打开与文件关联 | 文件菜单提供“最近打开文件”和“最近打开文件夹”，各保留最多 5 项，最新在前，同一路径重复打开置顶；设置中可注册 .md 文件关联，之后双击文件即可用 MDRE 打开。 |
| 编辑模式 | 左侧修改 Markdown 源码，右侧直接编辑排版结果，两栏同步，共用撤销与重做。拖动中间分隔条调整宽度，双击恢复均分。 |
| 阅读模式 | 在右下角选择“阅读模式”，查看排版结果；可选择、复制、查找与导出。Ctrl+Shift+V 切换模式。 |
| 侧栏与大纲 | 通过“侧栏”按钮或 Ctrl+Shift+O 收起／展开左侧区域，并在文件列表、图片管理与大纲导航之间切换。详细操作见下文。 |
| 专注模式 | F11 切换专注模式；底部视图按钮可切回全量编辑。 |

### 侧栏与大纲

侧栏文件操作按钮与文档标签位于同一行，依次提供新建文件、打开文件和打开文件夹功能。文件列表中的目录可展开，Markdown／文本文件单击打开，采用 Windows 文件关联图标。文件夹路径过长时省略，悬停可查看完整路径；刷新按钮重新读取目录。已打开文件夹时，左侧新建按钮会在该目录中新建未命名 Markdown 文件，并自动避开同名文件。拖动文件列表与已打开文档之间的分隔线可调整高度，两个区域分别支持滚动。

视图工具组或“查看”菜单中的“侧栏”命令控制整个左侧区域，提示随当前状态显示“收起侧栏”或“展开侧栏”；重新展开后保留文件列表、图片管理或大纲的选择。大纲按标题层级导航，点击标题将标题对齐到页面上方；蓝色条目随渲染页面滚动更新。条目保持原有高度，内容超出可用区域时可滚动查看。标题旁的箭头可折叠／展开大纲列表，侧栏右侧边缘可拖动调整宽度。

### 图片管理

侧栏顶部的按钮依次为“文件列表”、“图片管理”和“大纲导航”，点击“图片管理”在下方按当前渲染文档的引用顺序列出所引用的图片。

| 操作 | 方法 |
| --- | --- |
| 查看图片列表 | 打开含图片的文档后点击“图片管理”。列表显示图片名称与图片在电脑中的路径；名称过长时以省略号显示，悬停可查看完整内容。图片较多时可在面板内滚动查看。 |
| 跳转引用位置 | 单击条目，渲染栏滚动到对应图片并选中该图片位置。 |
| 打开所在目录 | 双击图片名称，使用系统文件资源管理器打开图片所在目录。 |
| 空状态 | 当前文档没有引用图片时，面板显示空状态提示。 |

面板随文档切换与预览刷新自动更新。网络图片显示原始 HTTPS 地址，内嵌图片显示“内嵌图片（data URI）”，这两类图片没有本地目录可打开。

### 欢迎页与会话恢复

欢迎页提示“打开 Markdown 文件，或开始一篇新文档”，提供新建文档与打开文件入口，文件列表仍可使用。编辑工具显示为禁用状态，将鼠标悬停于按钮上仍可查看名称。

启动时自动恢复上次的文件夹、尚未关闭的文件、当前标签，以及侧栏是否收起和显示文件列表、图片管理或大纲的状态。已关闭的标签不会恢复；正式文件读取磁盘上的最新内容，尚未保存的修改通过恢复快照恢复。无法打开的路径会提示并跳过，其余文件继续恢复。

## 编辑与排版

顶部编辑工具按历史、字体、色彩、段落、插入、结构分组，采用紧凑的单行排列，按钮与下方类别名统一对齐；窄窗口可横向滚动工具栏。文本渲染保留连续空格。组合格式在写回 Markdown 前进行重新解析校验；无法可靠保存的格式修改会显示错误提示，并保留原文。

| 功能 | 使用方法 |
| --- | --- |
| 基本格式 | 选中文字后使用顶部按钮或右键菜单设置粗体、斜体、删除线、字号、上下标、标题、列表、引用、链接等。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。 |
| 下划线 | 使用字体组 U 按钮、Ctrl+U 或右键“文字格式 → 下划线”设置。CommonMark 没有原生下划线标记，因此采用通用 HTML `<u>内容</u>`；可与粗体、斜体、删除线、颜色、公式等组合，富文本修改会写回源码。 |
| 文字颜色与高亮 | 颜色按钮旁的色块显示预选色，点击色块应用；选择颜色会更新预选色。右键“文字颜色”或“高亮”打开二级菜单，可应用、选色、恢复默认文字颜色或清除高亮。 |
| 表格 | 插入表格后在渲染栏直接输入，Enter 在格内换行；通过右键“表格”二级菜单插删行列、设置当前列（GFM 表格写分隔行）或当前单元格（HTML 表格）的左对齐／左右居中／右对齐。列宽、对齐、合并／拆分等操作见下文“表格操作”。 |
| 图片 | 插入按钮、拖入原文件、文件粘贴优先直接引用原文件绝对路径；截图等没有原文件的图片先保存在持久图片目录。默认等比适应正文宽度，原始尺寸模式恢复指定宽度。相对路径继续支持，assets 仅作兜底，未保存文档也能插图。 |
| 数学公式 | 使用 `$…$` 编写行内公式；块级公式的起止 `$$` 标记应分别独占一行。双击渲染栏公式进入 MathLive 可视化编辑，可点击虚拟键盘构造公式；块级公式支持编号设置。确认后写回源码，可通过一次撤销恢复原内容；取消或按 Esc 不会修改文档。不能可视化编辑的语法会提示在源码栏修改。 |
| Mermaid 图表 | 右键“插入 → Mermaid 图”打开源码弹窗；双击图表或点击“编辑图表”修改。渲染页面只显示图形，可用图表上的“删除”按钮删除，或选中图形后按 Delete／Backspace；源码栏也可直接修改。 |
| 代码块 | 渲染栏显示代码内容与固定行号，顶部可切换语言；展开后的可视区域最多容纳约 20 行，超出部分可在代码块内滚动查看，阅读模式也可展开或折叠。插入时下方自动新增空段落，点击即可输入。设置页可选择代码块浅色或深色主题。 |
| 源码片段 | HTML、front matter 等内容保留源码方式，可通过源码片段入口修改。右键插入菜单不提供“HTML 块”和“内联 HTML”入口，已有 HTML 源码仍可打开与编辑。 |
| 查找与替换 | Ctrl+F 查找，Ctrl+H 替换，支持正则、区分大小写和全字匹配；替换可撤销。可从菜单跳转到指定行。 |

具体写法见 [MDRE语法](MDRE语法.md)。

## 表格操作

表格在渲染栏中直接编辑。列宽、对齐与单元格结构通过鼠标拖动或右键“表格”菜单操作，一次操作算一步撤销。

| 操作 | 方法 |
| --- | --- |
| 调整列宽 | 将鼠标移到表格列边框，光标变为左右拖动箭头后按住拖动；拖动时实时预览（单列最小 4%、总宽保持 100%），松开后一次提交。双击列边框按该列内容自动适应宽度，其余列按现宽比例分配剩余空间。 |
| 列宽菜单 | 右键“表格”菜单中的“均分各列／适应内容／恢复自动列宽”三项。列宽百分比保存在表格后的注释中，其他 Markdown 编辑器会当作注释忽略。 |
| 水平对齐 | 右键“表格 → 左对齐／左右居中／右对齐”，三者互斥，勾选表示当前状态。GFM 表格的对齐写入分隔行（`:---`／`:---:`／`---:`），只影响选中单元格所在列，其余列保持原对齐；HTML 表格写入单元格 `text-align` 样式。 |
| 上下居中 | 右键“表格 → 上下居中”勾选。该项为独立开关，可与任一水平对齐同时生效。 |
| 选择单元格 | Ctrl 或 Cmd+单击切换单元格多选；Shift+单击从锚点按矩形范围选择；“全选表格”选中整表；也可在渲染栏拖选跨单元格的文字后操作，按选区覆盖的单元格处理。 |
| 合并单元格 | 选中矩形区域后右键“表格 → 合并单元格”。合并内容按阅读顺序用换行连接；非矩形区域等不合法选择会提示并且不修改文档。 |
| 拆分单元格 | 右键“表格 → 拆分单元格”。拆分后内容保留在左上单元格。 |
| 转换为 Markdown 表格 | 仅无合并、无上下居中的 HTML 表格可用：右键“表格 → 转换为 Markdown 表格”。执行前会列出会丢失的信息并需确认；列宽保留为 HTML 注释，水平对齐按每列首行写回分隔行。 |

首次合并单元格或首次启用“上下居中”时，整表会转为 HTML 表格，状态栏提示“此表已转为 HTML 表格，其他仅支持标准 Markdown 表格的编辑器可能显示源码”。此后 `rowspan`／`colspan`、单元格样式和 `colgroup` 列宽写入源码；仅支持标准 Markdown 表格的编辑器可能将其显示为源码。GFM 表格的列宽以 HTML 注释保存在表格后，例如 `<!-- mdre:table-widths: 25%,40%,35% -->`；插删列会同步更新注释，列数或注释数量不匹配时回退自动布局并提示。HTML／PDF 导出会保留列宽、合并单元格与水平／垂直对齐，合并单元格不会被跨页拆开。

## A4 与分页

“视图”组的纸张图标切换 A4 纸张显示，纸张尺寸为 **210 × 297 mm**。设置 → 纸张与图片 → A4 排版方式可选择连续排版或分页排版。编辑和阅读模式均可独立开关 A4，编辑模式仍能直接修改内容。

连续排版向下延伸；分页排版显示分开的纸张，长段落、列表和表格分别按视觉行、列表项和表格行跨页。特别高的不可分块或单元格使用块内滚动，以保留完整内容。页码、页间空白等显示布局不进入 Markdown，也不增加撤销步骤。

分页先按固定纸张尺寸完成排版，再整体缩放；缩放不改变分页划分。鼠标指针位于渲染页面内时，按住 Ctrl 并滚动鼠标滚轮可在 **25%–250%** 之间缩放。分页模式每页底部显示页码，右下角显示当前可见页、总页数和缩放比例；连续排版只显示缩放比例。

分页根据渲染栏的可用宽度，每行自动排列 **1–3 页**，高度不影响列数。页码从左到右、从上到下递增，例如第一行 1、2、3，第二行 4、5、6。

设置 → 纸张与图片 → A4 正文对齐可选择左对齐、居中、右对齐或两端对齐，默认为两端对齐。该设置影响 A4 连续与分页正文的显示。

## 保存、恢复与导出

- 有路径且已修改的文档默认每 60 秒自动保存；恢复快照独立记录编辑内容，启动时可恢复。恢复快照不代替正式保存。
- 保存前备份默认关闭；在设置中调整备份份数，0 表示关闭。
- 打开与保存支持 UTF-8、UTF-16LE/BE 和 GBK，沿用原文件编码、BOM 与换行；状态栏显示编码。无法按原编码保存时会提示，可选择转为 UTF-8。
- 磁盘文件被其他程序修改时，会提示重新加载、另存为或取消；关闭未保存文件时会询问处理方式。
- “导出”菜单可导出 HTML 或 PDF，嵌入本地图片并保留公式、图表的渲染结果；PDF 导出使用系统 WebView2 运行时。也可导出可分享副本。
- 较慢渲染会提示预览状态。文档源码的 UTF-8 编码大小达到 1 MiB 时，预览切换为手动刷新；此时使用刷新按钮或 Ctrl+Shift+R 更新预览。

### 导出可分享副本

“导出”菜单提供“导出可分享副本…”：把当前文档与被引用的图片打包成一个 zip 文件，Markdown 中的图片引用改写为 zip 内的相对路径。原本位于文档目录内、使用相对路径的图片保持原相对路径；绝对路径与全局图片库中的图片按内容哈希命名放入 zip 内的 `images/` 目录；无法读取的图片跳过，并在状态栏提示数量。原文档与源图片不变，HTTPS 与 data URI 图片不写入 zip。导出成功后在状态栏显示保存路径与文件大小。

## 复制与粘贴

渲染栏右键菜单的“复制／剪切／粘贴”区域提供“复制为富文本”（**Ctrl+Shift+C**）：有选区时复制选区，无选区时复制整篇渲染内容。复制时同时写入富文本与纯文本两种格式，粘贴到 Word、邮件或网页编辑器时保留标题、段落、粗体、斜体、下划线、删除线、列表、任务清单、引用、代码、链接、表格和图片，不包含页码、代码行号、纸张边距等界面装饰。源码栏的复制行为保持不变，仍输出纯 Markdown。MDRE 私有语法按最接近的语义降级：文字颜色处理为下划线，高亮与字号处理为加粗；无法映射的内容丢弃并在状态栏提示。复制成功后状态栏提示“已复制为富文本”，有降级或丢弃时追加数量。

源码栏与渲染栏都可使用 **Ctrl+V** 粘贴。剪贴板包含 HTML 时自动转换为 Markdown，没有 HTML 或转换失败时按纯文本粘贴；不新增顶部按钮和设置项，转换结果与忽略项通过状态栏提示。

| 内容 | 处理方式 |
| --- | --- |
| 标题、段落、列表、引用、代码块、链接、表格、换行 | 转换为对应 Markdown；代码块保留语言。 |
| 粗体、斜体、下划线、删除线、任务清单 | 转换为对应 Markdown 标记。 |
| Word 的 `MsoHeading*` 标题与 `mso-list` 列表、Excel 或网页表格 | 按结构识别并转换。 |
| 颜色、字体、字号、行距、对齐等 | Markdown 无法表达，忽略并提示“已忽略 N 项格式”。 |
| 合并单元格表格 | 降级为普通段落或文本并提示。 |
| 脚本、iframe、事件属性 | 转换前做白名单清洗，一律丢弃。 |
| Word 内嵌 data URI 图片 | 存入全局图片库（按内容哈希去重、引用绝对路径）。 |
| 网页 HTTPS 图片 | 保留链接；离线后可能无法显示。 |
| 无法读取的 Word 临时文件图片 | 跳过并提示数量。 |

粘贴内容体积过大或图片过多时会回退为纯文本：HTML 超过 5 MB 或图片超过 20 张时按纯文本粘贴并提示。源码栏按光标插入，渲染栏按选区替换；一次粘贴只产生一步撤销。输入法组合输入期间先提交再粘贴；代码块和行内代码内粘贴按纯文本处理，表格单元格内粘贴复杂内容按文本处理。右键“粘贴”菜单同样优先进行 HTML 转换（插件版右键粘贴依赖 VS Code 剪贴板读取能力）。

## 设置与帮助

“设置 → 打开设置页面”可调整主题、默认启动模式、字体、字号、行距、分栏比例、代码块主题、备份份数与快捷键，也可打开配置目录。“纸张与图片”设置默认 A4、连续／分页排版、A4 正文对齐和图片显示方式；“侧栏导航”设置侧栏宽度和大纲折叠状态。修改后保存即可作用于当前界面，下次启动时沿用已保存的配置；默认启动模式在下次启动时应用。取消或 Esc 放弃本次修改。

设置弹窗会按窗口空间调整尺寸，可拖动标题移动位置、拖动右下角调整大小；桌面应用初始窗口为 **1440 × 960 像素**。

点击顶部“帮助”直接打开离线帮助，默认显示“MDRE使用”；可切换语法、使用说明与技术声明，并筛选内容。弹窗标题可拖动，右下角可调整大小；Esc 关闭。

帮助与公式编辑资源随程序提供。文档中的外部链接仅在点击后交给系统浏览器打开。

工具栏超出窗口时，可用滚轮横向浏览：向后（向下）向右，向前（向上）向左。专注模式通过底部视图按钮切换，纸张页码与缩放信息在右下角。图片选择“适应正文宽度”时等比填满所在正文容器，包括带自定义宽度的图片；原始大小模式恢复源码指定宽度。

A4 显示源码时，两栏按可见文字位置双向滚动联动，兼容连续排版、分页、多列缩放及长段落跨页；另一栏的镜像滚动不会反向驱动。

## 操作提示

右键菜单将文字格式、插入、文字颜色、高亮、字号、表格和块操作分组。常用的复制、剪切、粘贴、撤销、重做保留在一级；上移、下移、删除、转换当前块及源码片段入口放在“块操作”中。正文不再跟随鼠标显示块操作悬浮条。

分隔线直接显示横线；HTML 显示预览，不在正文中展开源码框。需要修改时使用源码栏或“块操作 → 编辑源码片段”。代码块仍可直接编辑代码内容，公式与 Mermaid 沿用专用弹窗。

编辑和阅读模式均显示完整编辑工具；阅读模式将修改功能置灰，仍可查找、复制、导出、设置 A4 和缩放。页内链接可直接单击，包含显式标题 ID 的链接与文档目录共用标题锚点。

设置页按三列排列，窗口较窄时自动减少列数。主题保存后立即生效并在重新打开后恢复；桌面版“跟随系统”跟随操作系统，插件版优先跟随 VS Code 的主题。

## 0.2.5 图片、剪贴板与表格操作

- 侧栏新增“图片管理”，按引用顺序列出当前文档的图片，单击跳转、双击打开所在目录。
- 导出菜单新增“导出可分享副本…”，把文档与被引用图片打包为 zip。
- 渲染栏右键新增“复制为富文本”（Ctrl+Shift+C）；源码栏与渲染栏粘贴 HTML 时自动转换为 Markdown。
- 表格新增列宽拖拽与菜单、水平对齐与上下居中、合并／拆分单元格、转换为 Markdown 表格；列宽以 `<!-- mdre:table-widths: … -->` 注释保存，合并或上下居中的表格保存为 HTML 表格。详见“表格操作”。

## 0.2.4 视图、字号与编辑操作

右下角“选择视图模式”提供以下组合。手动更改为其他组合时显示“自由模式”。重新打开时恢复最后的组合，包括自由模式。

| 视图 | A4 | 源码栏 | 侧栏 | 编辑功能区 |
| --- | --- | --- | --- | --- |
| 全量编辑 | 关闭 | 显示 | 显示 | 显示 |
| 专注模式 | 开启 | 隐藏 | 显示 | 隐藏 |
| 沉浸专注 | 开启 | 隐藏 | 隐藏 | 隐藏 |
| A4视图 | 开启 | 隐藏 | 显示 | 显示 |

设置提供“默认侧栏状态”和“编辑功能区显示状态”。专注模式保留底部信息栏，可切换视图；F11 在专注模式与全量编辑间切换。插件隐藏编辑功能区时，导出及设置图标出现在右下角。

“外观与阅读 → 字号单位”选择 px 或 em，初始为 px。切换时正文字号按 16px = 1em 换算，视觉大小保持一致。字号按钮与右键预设仅显示所选单位；px 提供 8px 至 24px、间隔 2px 的预设。

右键顺序为“文字格式 → 文字颜色 → 标题 → 高亮 → 字号 → 插入 → 表格 → 块操作”。在表格中拖选文字范围，或 Ctrl／Cmd 点击多选单元格、Shift 点击选择矩形区域，再右键设置对齐；“表格 → 全选表格”可统一全表对齐。未选格的对齐保持原样，批量操作可一次撤销。

空列表项按 Backspace 或 Enter 可退出列表。分隔线可点击选中后按 Delete／Backspace 删除。普通段落的数字句点可写为 `1\. 说明`；`1. 说明` 与独占一行的 `1.` 按 Markdown 规则表示有序列表。旧数字实体继续兼容。复杂列表内额外空段会以 HTML 空段 `<p></p>` 保存，避免丢失段落层级。

查找提供上一个和下一个匹配，Enter 向后、Shift+Enter 向前；自动滚动到当前匹配。

有正式路径的修改文档每 60 秒自动保存，插件通过 VS Code 文档保存确认。无路径文档应先手动保存；组合输入、恢复副本、冲突中的文档会暂缓。底部左侧按“文件名 | 保存状态”排列，右侧为字符与词数、编码、行列、视图选项、编辑／阅读模式。

PDF 导出先选择“分页导出”或“长页导出”。前者使用 A4 分页，后者将全文排在一张纵向长页中。长页超过系统打印引擎上限时会提示使用分页导出。HTML 导出流程不变。
