# MDRE使用

MDRE **v0.1**（程序版本号 `0.1.0`）是本地 Markdown 编辑器，可在源码与排版结果之间同步编辑，也可切换到阅读模式。本页说明 v0.1 已实现的功能与操作方法。

## 文件与模式

| 功能 | 使用方法 |
| --- | --- |
| 新建、打开、保存 | 在“文件”菜单操作；默认快捷键为 Ctrl+N、Ctrl+O、Ctrl+S，另存为 Ctrl+Shift+S。 |
| 文件标签 | 同时打开多个文件；拖动标签调整顺序，Ctrl+Tab 切换，Ctrl+W 关闭。标签尾部加号打开新欢迎页，关闭最后一个标签后回到欢迎页。 |
| 最近打开与文件关联 | 文件菜单显示最近打开的 5 个文件，最新在前，超出时移除最早记录；设置中可注册 .md 文件关联，之后双击文件即可用 MDRE 打开。 |
| 编辑模式 | 左侧修改 Markdown 源码，右侧直接编辑排版结果，两栏同步，共用撤销与重做。拖动中间分隔条调整宽度，双击恢复均分。 |
| 阅读模式 | 在右下角选择“阅读模式”，查看排版结果；可选择、复制、查找与导出。Ctrl+Shift+V 切换模式。 |
| 大纲与专注 | 大纲按标题导航，Ctrl+Shift+O 切换显示；F11 进入专注模式，可通过悬浮按钮退出。 |

## 编辑与排版

| 功能 | 使用方法 |
| --- | --- |
| 基本格式 | 选中文字后使用顶部按钮或右键菜单设置粗体、斜体、删除线、字号、上下标、标题、列表、引用、链接等。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。 |
| 文字颜色与高亮 | 颜色按钮旁的色块显示预选色，点击色块应用；选择颜色会更新预选色。右键“文字”或“高亮”打开二级菜单，可应用、选色、恢复默认文字颜色或清除高亮。 |
| 表格 | 插入表格后在渲染栏直接输入；Tab / Shift+Tab 切换单元格，Enter 换行，右键增删行列。 |
| 图片 | 使用插入图片按钮、拖入文件或粘贴截图；图片保存到本地 assets 目录。选中后拖动手柄调整宽度，悬停查看缩略图，双击查看大图并旋转。 |
| 数学公式 | 使用 $…$ 或独占行的 $$ 写公式。双击渲染栏公式进入 MathLive 可视化编辑，可点击虚拟键盘构造公式；块级公式支持编号设置。确定后写回，一次撤销可恢复；取消或 Esc 不改文档。不能可视化编辑的语法会提示在源码栏修改。 |
| Mermaid 图表 | 在 mermaid 围栏代码块中写图表，渲染栏显示图形；在源码栏修改图表内容。 |
| 代码块 | 渲染栏显示代码内容与固定行号，顶部可切换语言；展开最多显示 20 行，超出部分用鼠标滚轮查看，阅读模式也可展开或折叠。插入时下方自动新增空段落，点击即可输入。设置页可选择代码块浅色或深色主题。 |
| 源码片段 | HTML、front matter 等内容保留源码方式；可通过源码片段入口修改。 |
| 查找与替换 | Ctrl+F 查找，Ctrl+H 替换，支持正则、区分大小写和全字匹配；替换可撤销。可从菜单跳转到指定行。 |

具体写法见 [MDRE语法](MDRE语法.md)。

## 保存、恢复与导出

- 有路径且已修改的文档默认每 60 秒自动保存；恢复快照独立记录编辑内容，启动时可恢复。恢复快照不代替正式保存。
- 保存前备份默认关闭；在设置中调整备份份数，0 表示关闭。
- 打开与保存支持 UTF-8、UTF-16LE/BE 和 GBK，沿用原文件编码、BOM 与换行；状态栏显示编码。无法按原编码保存时会提示，可选择转为 UTF-8。
- 磁盘文件被其他程序修改时，会提示重新加载、另存为或取消；关闭未保存文件时会询问处理方式。
- “导出”菜单可导出 HTML 或 PDF，嵌入本地图片并保留公式、图表的渲染结果；PDF 不设置文件大小上限。
- 较慢渲染会显示耗时。大文档进入手动刷新状态后，使用刷新按钮或 Ctrl+Shift+R 更新预览。

## 设置与帮助

“设置 → 打开设置页面”可调整主题、默认启动模式、字体字号、行距、分栏比例、备份份数与快捷键，也可打开配置目录。修改后保存，取消或 Esc 放弃本次修改；默认启动模式在下次启动时应用。

点击顶部“帮助”直接打开离线帮助，默认显示“MDRE使用”；可切换语法、使用说明与技术声明，并筛选内容。弹窗标题可拖动，右下角可调整大小；Esc 关闭。

帮助与公式编辑资源随程序提供。文档中的外部链接仅在点击后交给系统浏览器打开。
