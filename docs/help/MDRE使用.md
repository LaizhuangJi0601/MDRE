# MDRE 使用说明

MDRE **0.2.1** 是本地 Markdown 编辑器，支持源码与富文本双向编辑，并提供阅读模式。本页说明当前版本的功能与操作方法。

## 文件与模式

| 功能 | 使用方法 |
| --- | --- |
| 新建、打开、保存 | 在“文件”菜单操作；默认快捷键为 Ctrl+N、Ctrl+O、Ctrl+S，另存为 Ctrl+Shift+S。 |
| 文件标签 | 同时打开多个文件；拖动标签调整顺序，Ctrl+Tab 切换，Ctrl+W 关闭。标签尾部加号打开新欢迎页，关闭最后一个标签后回到欢迎页。 |
| 最近打开与文件关联 | 文件菜单提供“最近打开文件”和“最近打开文件夹”，各保留最多 5 项，最新在前，同一路径重复打开置顶；设置中可注册 .md 文件关联，之后双击文件即可用 MDRE 打开。 |
| 编辑模式 | 左侧修改 Markdown 源码，右侧直接编辑排版结果，两栏同步，共用撤销与重做。拖动中间分隔条调整宽度，双击恢复均分。 |
| 阅读模式 | 在右下角选择“阅读模式”，查看排版结果；可选择、复制、查找与导出。Ctrl+Shift+V 切换模式。 |
| 侧栏与大纲 | 通过“侧栏”按钮或 Ctrl+Shift+O 收起／展开左侧区域，并在文件列表与大纲导航之间切换。详细操作见下文。 |
| 专注模式 | F11 进入专注模式，可通过悬浮按钮退出。 |

### 侧栏与大纲

侧栏文件操作按钮与文档标签位于同一行，依次提供新建文件、打开文件和打开文件夹功能。文件列表中的目录可展开，Markdown／文本文件单击打开，采用 Windows 文件关联图标。文件夹路径过长时省略，悬停可查看完整路径；刷新按钮重新读取目录。已打开文件夹时，左侧新建按钮会在该目录中新建未命名 Markdown 文件，并自动避开同名文件。拖动文件列表与已打开文档之间的分隔线可调整高度，两个区域分别支持滚动。

视图工具组或“查看”菜单中的“侧栏”命令控制整个左侧区域，提示随当前状态显示“收起侧栏”或“展开侧栏”；重新展开后保留文件列表或大纲的选择。大纲按标题层级导航，点击标题将标题对齐到页面上方；蓝色条目随渲染页面滚动更新。条目保持原有高度，内容超出可用区域时可滚动查看。标题旁的箭头可折叠／展开大纲列表，侧栏右侧边缘可拖动调整宽度。

### 欢迎页与会话恢复

欢迎页提示“打开 Markdown 文件，或开始一篇新文档”，提供新建文档与打开文件入口，文件列表仍可使用。编辑工具显示为禁用状态，将鼠标悬停于按钮上仍可查看名称。

启动时自动恢复上次的文件夹、尚未关闭的文件、当前标签，以及侧栏是否收起和显示文件列表／大纲的状态。已关闭的标签不会恢复；正式文件读取磁盘上的最新内容，尚未保存的修改通过恢复快照恢复。无法打开的路径会提示并跳过，其余文件继续恢复。

## 编辑与排版

顶部编辑工具按历史、字体、色彩、段落、插入、结构分组，采用紧凑的单行排列，按钮与下方类别名统一对齐；窄窗口可横向滚动工具栏。文本渲染保留连续空格。组合格式在写回 Markdown 前进行重新解析校验；无法可靠保存的格式修改会显示错误提示，并保留原文。

| 功能 | 使用方法 |
| --- | --- |
| 基本格式 | 选中文字后使用顶部按钮或右键菜单设置粗体、斜体、删除线、字号、上下标、标题、列表、引用、链接等。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。 |
| 下划线 | 使用字体组 U 按钮、Ctrl+U 或右键“文字格式 → 下划线”设置。CommonMark 没有原生下划线标记，因此采用通用 HTML `<u>内容</u>`；可与粗体、斜体、删除线、颜色、公式等组合，富文本修改会写回源码。 |
| 文字颜色与高亮 | 颜色按钮旁的色块显示预选色，点击色块应用；选择颜色会更新预选色。右键“文字”或“高亮”打开二级菜单，可应用、选色、恢复默认文字颜色或清除高亮。 |
| 表格 | 插入表格后在渲染栏直接输入，Enter 在格内换行；通过右键“表格”二级菜单插删行列或设置当前单元格左对齐、居中、右对齐，勾选表示当前状态。 |
| 图片 | 插入按钮、拖入原文件、文件粘贴优先直接引用原文件绝对路径；截图等没有原文件的图片先保存在持久图片目录。默认等比适应正文宽度，原始尺寸模式恢复指定宽度。相对路径继续支持，assets 仅作兜底，未保存文档也能插图。 |
| 数学公式 | 使用 `$…$` 编写行内公式；块级公式的起止 `$$` 标记应分别独占一行。双击渲染栏公式进入 MathLive 可视化编辑，可点击虚拟键盘构造公式；块级公式支持编号设置。确认后写回源码，可通过一次撤销恢复原内容；取消或按 Esc 不会修改文档。不能可视化编辑的语法会提示在源码栏修改。 |
| Mermaid 图表 | 右键“插入 → Mermaid 图”打开源码弹窗；双击图表或点击“编辑图表”修改。渲染页面只显示图形，可用图表上的“删除”按钮删除，或选中图形后按 Delete／Backspace；源码栏也可直接修改。 |
| 代码块 | 渲染栏显示代码内容与固定行号，顶部可切换语言；展开后的可视区域最多容纳约 20 行，超出部分可在代码块内滚动查看，阅读模式也可展开或折叠。插入时下方自动新增空段落，点击即可输入。设置页可选择代码块浅色或深色主题。 |
| 源码片段 | HTML、front matter 等内容保留源码方式，可通过源码片段入口修改。右键插入菜单不提供“HTML 块”和“内联 HTML”入口，已有 HTML 源码仍可打开与编辑。 |
| 查找与替换 | Ctrl+F 查找，Ctrl+H 替换，支持正则、区分大小写和全字匹配；替换可撤销。可从菜单跳转到指定行。 |

具体写法见 [MDRE语法](MDRE语法.md)。

## A4 与分页

“视图”组的纸张图标切换 A4 纸张显示，纸张尺寸为 **210 × 297 mm**。设置 → 纸张与图片 → A4 排版方式可选择连续排版或分页排版。编辑和阅读模式均可独立开关 A4，编辑模式仍能直接修改内容。

连续排版向下延伸；分页排版显示分开的纸张，长段落、列表和表格分别按视觉行、列表项和表格行跨页。特别高的不可分块或单元格使用块内滚动，以保留完整内容。页码、页间空白等显示布局不进入 Markdown，也不增加撤销步骤。

分页先按固定纸张尺寸完成排版，再整体缩放；缩放不改变分页划分。鼠标指针位于渲染页面内时，按住 Ctrl 并滚动鼠标滚轮可在 **25%–250%** 之间缩放。分页模式每页底部显示页码，右下角显示当前可见页、总页数和缩放比例；连续排版只显示缩放比例。

分页根据渲染栏的可用宽度，每行自动排列 **1–3 页**，高度不影响列数。页码从左到右、从上到下递增，例如第一行 1、2、3，第二行 4、5、6。

设置 → 纸张与图片 → A4 正文对齐可选择左对齐、居中、右对齐或两端对齐，默认为两端对齐。该设置影响 A4 连续与分页正文的显示。

## 保存、恢复与导出

- 有路径且已修改的文档默认每 60 秒自动保存；恢复快照独立记录编辑内容，启动时可恢复。恢复快照不代替正式保存。
- 保存前备份默认关闭；在设置中调整备份份数，0 表示关闭。
- 打开与保存支持 UTF-8、UTF-16LE/BE 和 GBK，沿用原文件编码、BOM 与换行；状态栏显示编码。无法按原编码保存时会提示，可选择转为 UTF-8。
- 磁盘文件被其他程序修改时，会提示重新加载、另存为或取消；关闭未保存文件时会询问处理方式。
- “导出”菜单可导出 HTML 或 PDF，嵌入本地图片并保留公式、图表的渲染结果；PDF 导出使用系统 WebView2 运行时。
- 较慢渲染会显示耗时。文档源码的 UTF-8 编码大小达到 1 MiB 时，预览切换为手动刷新；此时使用刷新按钮或 Ctrl+Shift+R 更新预览。

## 设置与帮助

“设置 → 打开设置页面”可调整主题、默认启动模式、字体、字号、行距、分栏比例、代码块主题、备份份数与快捷键，也可打开配置目录。“纸张与图片”设置默认 A4、连续／分页排版、A4 正文对齐和图片显示方式；“侧栏导航”设置侧栏宽度和大纲折叠状态。修改后保存即可作用于当前界面，下次启动时沿用已保存的配置；默认启动模式在下次启动时应用。取消或 Esc 放弃本次修改。

设置弹窗会按窗口空间调整尺寸，可拖动标题移动位置、拖动右下角调整大小；桌面应用初始窗口为 **1440 × 960 像素**。

点击顶部“帮助”直接打开离线帮助，默认显示“MDRE使用”；可切换语法、使用说明与技术声明，并筛选内容。弹窗标题可拖动，右下角可调整大小；Esc 关闭。

帮助与公式编辑资源随程序提供。文档中的外部链接仅在点击后交给系统浏览器打开。

工具栏超出窗口时，可用滚轮横向浏览：向后（向下）向右，向前（向上）向左。专注模式出口在右上角，纸张页码与缩放信息在右下角。图片选择“适应正文宽度”时等比填满所在正文容器，包括带自定义宽度的图片；原始大小模式恢复源码指定宽度。

A4 显示源码时，两栏按可见文字位置双向滚动联动，兼容连续排版、分页、多列缩放及长段落跨页；另一栏的镜像滚动不会反向驱动。

## 0.2.1 操作提示

右键菜单将文字格式、插入、文字颜色、高亮、字号、表格和块操作分组。常用的复制、剪切、粘贴、撤销、重做保留在一级；上移、下移、删除、转换当前块及源码片段入口放在“块操作”中。正文不再跟随鼠标显示块操作悬浮条。

分隔线直接显示横线；HTML 显示预览，不在正文中展开源码框。需要修改时使用源码栏或“块操作 → 编辑源码片段”。代码块仍可直接编辑代码内容，公式与 Mermaid 沿用专用弹窗。

编辑和阅读模式均显示完整编辑工具；阅读模式将修改功能置灰，仍可查找、复制、导出、设置 A4 和缩放。页内链接可直接单击，包含显式标题 ID 的链接与文档目录共用标题锚点。

设置页按三列排列，窗口较窄时自动减少列数。主题保存后立即生效并在重新打开后恢复；桌面版“跟随系统”跟随操作系统，插件版优先跟随 VS Code 的主题。
